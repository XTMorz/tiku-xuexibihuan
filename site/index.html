          把题库同步到你的 GitHub Gist（私密代码片段），所有设备只要填同一个 Token + Gist ID 就能共用一份数据。
    
          首次使用步骤：
        
    
        
      
          
    1. 访问 GitHub Fine-grained Token，新建一个
      2. 
          
    2. 权限只勾选 Gists: Read and write，无需其它权限
      3. 
          
    3. 把生成的 Token（github_pat_xxx...）粘到下方
      4. 
          
    4. 点「创建 Gist」按钮，系统自动建好并填回 ID；之后所有设备共用同一个 Gist ID
